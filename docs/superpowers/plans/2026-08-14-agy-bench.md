# agy-agents Benchmark Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure what share of implementation work the AGY implementer actually does, and compare Claude-only development against agy-agents deployment on active time, credit usage, and notional cost.

**Architecture:** A one-way post-hoc pipeline. `dispatch` and a new `solo` bracket persist per-run measurements into the existing `.class` sidecar files; a node scraper (`bench/collect`) reads those plus Claude session JSONL plus `git log` and emits a single `runs.json`; a node emitter (`bench/dashboard`) turns `runs.json` into one self-contained static HTML file. Nothing downstream writes upstream, so a broken dashboard cannot corrupt measurement.

**Tech Stack:** bash (`set -uo pipefail`, tab-indented, matching `assets/dispatch`), node CommonJS with **zero dependencies** (no `package.json`, no `npm install`), plain HTML/CSS/JS emitted as a string. Tests are assertions appended to `agy-agents/scripts/selftest`.

**Spec:** `docs/superpowers/specs/2026-08-14-agy-bench-design.md`

## Global Constraints

- **No third-party dependencies anywhere.** Node code uses only `fs`, `path`, `child_process`, `os`. The emitted HTML loads nothing over the network — no CDN, no fonts, no images.
- **Every shell script starts `set -uo pipefail`** and indents with **tabs**, matching `assets/dispatch` and `assets/install`.
- **Every refusal prints a verdict block to stderr and exits non-zero.** Reuse the exact `die()` shape already in `assets/dispatch` (lines 118–128): a `--- verdict ---` rule, `run  DID NOT RUN — <headline>`, optional detail lines, `exit  <code>`, then the closing "Nothing was dispatched" sentence. The verdict block and the exit code must agree.
- **An absent measurement is never read as zero.** Missing instrumentation yields `quality: "partial"`, never `0` tokens or `0` seconds.
- **No blended cost across the two subscriptions.** Claude credits and agy quota are reported on separate axes and are never summed, at any point, in any view.
- **Idle-gap threshold** is `BENCH_IDLE_GAP`, default `600` seconds.
- **Claude projects slug** is the working directory with each of `:`, `\`, `/`, and space replaced by `-`. For `d:\Claude Code\DTS Skills` that is `d--Claude-Code-DTS-Skills`. Verified against disk.
- **`agy-agents/scripts/selftest` must report 0 failed** after every task. It currently reports **162 passed, 0 failed**; each task below raises that number.
- **Do not run the real `agy` CLI.** The selftest stubs it and aborts if the real binary resolves on PATH.

**Deviations from the spec, decided here:**

1. **`solo` lives at `assets/solo` → `.agy/solo`**, not under `bench/`. It is a user-facing command like `.agy/dispatch`; `bench/` holds the read-only engine.
2. **`collect` is split into `bench/lib/*.js`.** The spec described one program; four readers plus cost in one file would grow past the size where edits stay reliable.
3. **`phase` and per-record `provenance` are dropped from the run record.** The spec gave every record a `phase` of `plan|implement|review|verify|solo` and its own `provenance`. In the implementation neither survives contact: the agy reader emits exactly one record per run (the run *is* the implement phase), and Claude's turns are aggregated into a single `claude` block split by `isSidechain` rather than into per-phase records — there is no marker in a transcript saying where planning ended and verification began. Provenance is likewise a property of the comparison, not of a run: it is `controlled` when a solo arm exists and `observational` when it does not, so the dashboard derives it once. Anything finer would require Claude to mark its own phase boundaries, which is instrumentation the spec explicitly did not want.
4. **The skip rule is corrected.** The spec says a truncated NDJSON goes to `skipped[]`. That is wrong: a *deferred* run has a truncated stream by definition and is a real run that did real work — skipping it would undercount precisely the longest agy runs. Corrected rule: **skip when the `.class` sidecar is missing or has no `status=` key.** The `.class` file is what the run's own parser wrote, so its absence means the parser never completed, which is the real "this run was not measured" signal.

- [ ] **Step 3: Write `agy-agents/assets/solo`**

```bash
#!/usr/bin/env bash
#
# The Claude-only baseline arm.
#
#   solo <task-number>    open a bracket — you then do the task yourself
#   solo --done           close it, and record what landed
#
# This script runs no model and makes no decisions. Its whole job is to make a
# task Claude did alone leave the same shape of trace an agy run leaves, so the
# two arms are measured by identical code rather than by two code paths that
# drift apart. Without it the benchmark has one arm and no comparison.

set -uo pipefail

die() { # die <exit-code> <headline> [extra lines...]
	code="$1"; headline="$2"; shift 2
	{
		printf -- '\n--- verdict --------------------------------------------------------\n'
		printf '  %-7s %s\n' run "DID NOT RUN — $headline"
		while [ $# -gt 0 ]; do printf '  %-7s %s\n' '' "$1"; shift; done
		printf '  %-7s %s\n' exit "$code"
		printf '\n  Nothing was recorded: the bracket is unchanged and the tree is untouched.\n'
	} >&2
	exit "$code"
}

git rev-parse --show-toplevel >/dev/null 2>&1 \
	|| die 2 'not a git repository' 'the benchmark reads git history to see what landed'
ROOT="$(git rev-parse --show-toplevel)"
cd "$ROOT" || die 2 "cannot enter the repository root ($ROOT)"

: "${AGY_WORKSPACE:=.agy/work}"
LOGDIR="$AGY_WORKSPACE/logs"
OPEN="$LOGDIR/.solo-open"
mkdir -p "$LOGDIR"

if [ "${1:-}" = "--done" ]; then
	[ -f "$OPEN" ] || die 2 'no open solo bracket' \
		'open one with `.agy/solo <task-number>` before closing it'
	CLASS="$(head -1 "$OPEN")"
	[ -f "$CLASS" ] || die 2 "the open bracket points at a missing file ($CLASS)" \
		'delete .agy/work/logs/.solo-open and open a fresh bracket'

	STARTED="$(awk -F= '$1=="started"{print $2}' "$CLASS")"
	WAS_HEAD="$(awk -F= '$1=="head"{print $2}' "$CLASS")"
	ENDED="$(date +%s)"
	IS_HEAD="$(git rev-parse HEAD 2>/dev/null)"

	COMMITS=0; RANGE=""
	if [ -n "$WAS_HEAD" ] && [ -n "$IS_HEAD" ] && [ "$WAS_HEAD" != "$IS_HEAD" ] \
		&& git merge-base --is-ancestor "$WAS_HEAD" "$IS_HEAD" 2>/dev/null; then
		COMMITS="$(git rev-list --count "$WAS_HEAD..$IS_HEAD" 2>/dev/null || printf 0)"
		RANGE="$WAS_HEAD..$IS_HEAD"
	fi

	{
		printf 'ended=%s\n' "$ENDED"
		printf 'wall=%s\n' "$(( ENDED - STARTED ))"
		printf 'commits=%s\n' "$COMMITS"
		printf 'range=%s\n' "$RANGE"
		printf 'status=success\n'
	} >> "$CLASS"
	rm -f "$OPEN"

	printf '\n--- solo -----------------------------------------------------------\n'
	printf '  %-7s %s\n' closed "$(awk -F= '$1=="task"{print $2}' "$CLASS")"
	printf '  %-7s %ss\n' wall "$(( ENDED - STARTED ))"
	printf '  %-7s %s\n' landed "$COMMITS commit(s)"
	printf '  %-7s %s\n' log "$CLASS"
	printf '\n  Recorded as the Claude-only arm. Nothing here is a measurement of\n'
	printf '  agy: this run is the thing agy is being compared against.\n'
	exit 0
fi

N="${1:-}"
case "$N" in
	''|*[!0-9]*) die 2 'no task number given' \
		'usage: .agy/solo <task-number> | .agy/solo --done' ;;
esac

if [ -f "$OPEN" ]; then
	PREV="$(head -1 "$OPEN")"
	die 2 "a solo bracket is already open ($(awk -F= '$1=="task"{print $2}' "$PREV" 2>/dev/null))" \
		'close it with `.agy/solo --done` first — overlapping brackets cannot be attributed'
fi

STAMP="$(date +%Y%m%d-%H%M%S)"
CLASS="$LOGDIR/solo-task-$N-$STAMP.class"
{
	printf 'arm=solo\n'
	printf 'task=task-%s\n' "$N"
	printf 'started=%s\n' "$(date +%s)"
	printf 'head=%s\n' "$(git rev-parse HEAD 2>/dev/null)"
	printf 'status=open\n'
} > "$CLASS"
printf '%s\n' "$CLASS" > "$OPEN"

printf '\n--- solo -----------------------------------------------------------\n'
printf '  %-7s %s\n' opened "task-$N"
printf '  %-7s %s\n' head "$(git rev-parse --short HEAD 2>/dev/null)"
printf '  %-7s %s\n' log "$CLASS"
printf '\n  Do the task yourself, commit it, then run `.agy/solo --done`.\n'
printf '  An unclosed bracket records nothing at all.\n'
```

- [ ] **Step 3: Write `agy-agents/assets/bench/lib/clip.js`**

```js
'use strict';
//
// Active time, with human-idle gaps removed.
//
// A task run across a lunch break and a task run in one sitting are not
// different-speed tasks, but raw elapsed time says they are — and one overnight
// gap would decide the whole comparison. So gaps longer than the threshold are
// excluded, uniformly, whether they fall inside a phase or between two phases.
// Elapsed is kept beside it because clipping is a judgement and the reader is
// entitled to see the number it was applied to.

const IDLE_GAP_DEFAULT = 600;

function clipActive(stampsMs, gapS) {
	const t = [...stampsMs].filter(n => Number.isFinite(n)).sort((a, b) => a - b);
	let total = 0;
	for (let i = 1; i < t.length; i++) {
		const d = (t[i] - t[i - 1]) / 1000;
		if (d <= gapS) total += d;
	}
	return Math.round(total);
}

function elapsed(stampsMs) {
	const t = [...stampsMs].filter(n => Number.isFinite(n)).sort((a, b) => a - b);
	if (t.length < 2) return 0;
	return Math.round((t[t.length - 1] - t[0]) / 1000);
}

module.exports = { clipActive, elapsed, IDLE_GAP_DEFAULT };
```

```js
'use strict';
//
// Reads the per-run sidecars the harness already writes.
//
// The skip rule is the load-bearing decision here. A truncated NDJSON is NOT a
// reason to skip: a deferred run has a truncated stream by definition, and it
// is usually the longest run in the set. Dropping those would bias the split
// toward the short, tidy runs. The real "this was never measured" signal is a
// stream with no .class sidecar, because the sidecar is what the parser writes
// when it completes.

const fs = require('fs');
const path = require('path');

function parseClass(text) {
	const out = {};
	for (const line of text.split('\n')) {
		const i = line.indexOf('=');
		if (i > 0) out[line.slice(0, i)] = line.slice(i + 1);
	}
	return out;
}

// An absent count is null, never 0: 'the model reported nothing' and 'the model
// used nothing' are different facts, and only one of them is free.
const num = v => (v === undefined || v === '' || v === null) ? null
	: (Number.isFinite(Number(v)) ? Number(v) : null);

function taskOf(base) {
	const m = base.match(/task-(\d+)/);
	return m ? `task-${m[1]}` : 'unknown';
}

function readRuns(logDir) {
	const runs = [];
	const skipped = [];
	let entries = [];
	try {
		entries = fs.readdirSync(logDir);
	} catch (e) {
		return { runs, skipped: [{ path: logDir, reason: 'log directory unreadable' }] };
	}

	for (const name of entries.filter(n => n.endsWith('.ndjson')).sort()) {
		const base = name.replace(/\.ndjson$/, '');
		if (!entries.includes(base + '.class')) {
			skipped.push({ path: path.join(logDir, name), reason: 'no .class sidecar — the run was never measured' });
		}
	}

	for (const name of entries.filter(n => n.endsWith('.class')).sort()) {
		const full = path.join(logDir, name);
		const base = name.replace(/\.class$/, '');
		let c;
		try {
			c = parseClass(fs.readFileSync(full, 'utf8'));
		} catch (e) {
			skipped.push({ path: full, reason: 'class sidecar unreadable' });
			continue;
		}
		if (!('status' in c)) {
			skipped.push({ path: full, reason: 'class sidecar has no status key' });
			continue;
		}

		const arm = c.arm === 'solo' ? 'solo' : 'agy';
		const wall = num(c.wall);
		const total = num(c.tokens_total);
		const status = c.deferred === '1' ? 'deferred' : (c.status || 'unknown');

		// An open solo bracket is not a run yet. Counting it would report a task
		// that is still being worked on as one that finished in zero seconds.
		if (arm === 'solo' && c.status === 'open') {
			skipped.push({ path: full, reason: 'solo bracket still open — close it with `.agy/solo --done`' });
			continue;
		}

		runs.push({
			arm,
			task: c.task || taskOf(base),
			label: base,
			started: num(c.started) === null ? null : num(c.started) * 1000,
			wall,
			model: c.model || (arm === 'solo' ? '' : 'unknown'),
			tokens: {
				in: num(c.tokens_in), out: num(c.tokens_out),
				think: num(c.tokens_think), total,
			},
			tools: num(c.tools),
			commits: num(c.commits),
			range: c.range || '',
			status,
			quality: (arm === 'solo')
				? (wall === null ? 'partial' : 'full')
				: ((wall === null || total === null) ? 'partial' : 'full'),
			path: full,
		});
	}

	return { runs, skipped };
}

module.exports = { readRuns, parseClass };
```

```js
'use strict';
//
// Reads Claude Code session transcripts.
//
// isSidechain is the whole reason this is cheap: it separates the reviewer
// subagent's turns from the main thread with no new instrumentation, which is
// exactly the split the Effort panel needs. Cache reads and writes are broken
// out too, so cost prices them at their real rates instead of counting a cache
// hit as fresh input — which would inflate Claude's side several-fold.

const fs = require('fs');
const path = require('path');
const { clipActive, elapsed } = require('./clip.js');

function slugFor(cwd) {
	return String(cwd).replace(/[:\\/ ]/g, '-');
}

function readTurns(projectsDir, slug) {
	const dir = path.join(projectsDir, slug);
	let files = [];
	try {
		files = fs.readdirSync(dir).filter(n => n.endsWith('.jsonl'));
	} catch (e) {
		return [];
	}

	const turns = [];
	for (const f of files.sort()) {
		let text = '';
		try { text = fs.readFileSync(path.join(dir, f), 'utf8'); } catch (e) { continue; }
		for (const line of text.split('\n')) {
			if (!line) continue;
			let j;
			// A half-written last line is normal in a live session. Skipping it
			// loses one turn; aborting the file would lose the whole session.
			try { j = JSON.parse(line); } catch (e) { continue; }
			if (j.type !== 'assistant') continue;
			const u = (j.message && j.message.usage) || null;
			if (!u) continue;
			const ts = Date.parse(j.timestamp);
			if (!Number.isFinite(ts)) continue;
			turns.push({
				ts,
				model: (j.message && j.message.model) || 'unknown',
				sidechain: j.isSidechain === true,
				session: j.sessionId || f.replace(/\.jsonl$/, ''),
				tokens: {
					in: u.input_tokens || 0,
					out: u.output_tokens || 0,
					think: (u.output_tokens_details && u.output_tokens_details.thinking_tokens) || 0,
					cache_read: u.cache_read_input_tokens || 0,
					cache_write: u.cache_creation_input_tokens || 0,
				},
			});
		}
	}
	turns.sort((a, b) => a.ts - b.ts);
	return turns;
}

function blank() {
	return { turns: 0, in: 0, out: 0, think: 0, cache_read: 0, cache_write: 0 };
}

function summarise(turns, gapS) {
	const main = blank();
	const side = blank();
	for (const t of turns) {
		const bucket = t.sidechain ? side : main;
		bucket.turns++;
		bucket.in += t.tokens.in;
		bucket.out += t.tokens.out;
		bucket.think += t.tokens.think;
		bucket.cache_read += t.tokens.cache_read;
		bucket.cache_write += t.tokens.cache_write;
	}
	const stamps = turns.map(t => t.ts);
	return {
		active_s: clipActive(stamps, gapS),
		elapsed_s: elapsed(stamps),
		main,
		sidechain: side,
	};
}

module.exports = { slugFor, readTurns, summarise };
```

```js
'use strict';
//
// What actually landed, according to git rather than according to a report.
// This is the only source in the benchmark that a model cannot influence by
// describing its work more generously.

const { execFileSync } = require('child_process');

function numstat(range, cwd) {
	const zero = { commits: 0, insertions: 0, deletions: 0 };
	if (!range) return zero;
	let out = '';
	try {
		out = execFileSync('git', ['log', '--numstat', '--format=%H', range],
			{ cwd, encoding: 'utf8', stdio: ['ignore', 'pipe', 'ignore'] });
	} catch (e) {
		// A range whose commits have been rebased away is not an error worth
		// aborting a whole scrape for. It is one run that cannot be attributed.
		return zero;
	}
	let commits = 0, insertions = 0, deletions = 0;
	for (const line of out.split('\n')) {
		if (!line.trim()) continue;
		if (/^[0-9a-f]{7,40}$/.test(line.trim())) { commits++; continue; }
		const m = line.split('\t');
		if (m.length >= 3) {
			// '-' is git's marker for a binary file; it is not a line count.
			if (m[0] !== '-') insertions += Number(m[0]) || 0;
			if (m[1] !== '-') deletions += Number(m[1]) || 0;
		}
	}
	return { commits, insertions, deletions };
}

module.exports = { numstat };
```

```js
'use strict';
//
// Notional USD. Neither tool is billed per token under these subscriptions, so
// this is a comparison denominator, not a bill — every view that shows it must
// say so. An unknown model prices to null rather than zero: a model we have no
// rate for is not a model that was free, and a silent zero would flatter
// whichever side happened to be unrecognised.

const fs = require('fs');

function loadPrices(file) {
	return JSON.parse(fs.readFileSync(file, 'utf8'));
}

// Thinking tokens are billed as output and are already included in
// output_tokens by both vendors, so they are not charged again here.
function priceOf(model, tokens, prices) {
	const table = (prices && prices.models) || {};
	let rate = table[model];
	if (!rate) {
		const key = Object.keys(table).find(k => String(model).startsWith(k));
		rate = key ? table[key] : null;
	}
	if (!rate) return { usd: null, priced: false };
	const m = 1e6;
	const usd =
		((tokens.in || 0) / m) * (rate.in || 0) +
		((tokens.out || 0) / m) * (rate.out || 0) +
		((tokens.cache_read || 0) / m) * (rate.cache_read || 0) +
		((tokens.cache_write || 0) / m) * (rate.cache_write || 0);
	return { usd: Math.round(usd * 10000) / 10000, priced: true };
}

module.exports = { loadPrices, priceOf };
```

```js
#!/usr/bin/env node
'use strict';
//
// The scraper. Reads logs, transcripts and git; writes one runs.json.
//
// It is deliberately the only thing that reads a log and the only thing that
// writes runs.json. The dashboard reads runs.json and nothing else, so a bug in
// rendering can never corrupt a measurement, and a number that looks wrong can
// be checked by opening one JSON file rather than by re-running a scrape.
//
//   collect                 read $AGY_WORKSPACE and write its bench/runs.json
//
// Environment:
//   AGY_WORKSPACE           default .agy/work
//   BENCH_IDLE_GAP          default 600 (seconds)
//   CLAUDE_PROJECTS_DIR     default ~/.claude/projects
//   CLAUDE_PROJECT_SLUG     default: derived from the repo root

const fs = require('fs');
const os = require('os');
const path = require('path');
const { execFileSync } = require('child_process');

const agy = require(path.join(__dirname, 'lib', 'agy.js'));
const claude = require(path.join(__dirname, 'lib', 'claude.js'));
const { numstat } = require(path.join(__dirname, 'lib', 'gitwork.js'));
const { loadPrices, priceOf } = require(path.join(__dirname, 'lib', 'cost.js'));
const { IDLE_GAP_DEFAULT } = require(path.join(__dirname, 'lib', 'clip.js'));

function fail(code, headline, ...detail) {
	process.stderr.write('\n--- verdict --------------------------------------------------------\n');
	process.stderr.write(`  ${'run'.padEnd(7)} DID NOT RUN — ${headline}\n`);
	for (const d of detail) process.stderr.write(`  ${''.padEnd(7)} ${d}\n`);
	process.stderr.write(`  ${'exit'.padEnd(7)} ${code}\n`);
	process.stderr.write('\n  Nothing was collected: no file was written.\n');
	process.exit(code);
}

let root;
try {
	root = execFileSync('git', ['rev-parse', '--show-toplevel'],
		{ encoding: 'utf8', stdio: ['ignore', 'pipe', 'ignore'] }).trim();
} catch (e) {
	fail(2, 'not a git repository',
		'the benchmark attributes landed work by git history');
}

const workspace = process.env.AGY_WORKSPACE || '.agy/work';
const logDir = path.join(root, workspace, 'logs');
if (!fs.existsSync(logDir)) {
	fail(2, `no log directory at ${path.join(workspace, 'logs')}`,
		'run a dispatch or a solo bracket first — there is nothing to measure');
}

const gapS = Number(process.env.BENCH_IDLE_GAP || IDLE_GAP_DEFAULT) || IDLE_GAP_DEFAULT;
const projectsDir = process.env.CLAUDE_PROJECTS_DIR
	|| path.join(os.homedir(), '.claude', 'projects');
const slug = process.env.CLAUDE_PROJECT_SLUG || claude.slugFor(root);

const prices = loadPrices(path.join(__dirname, 'prices.json'));
const { runs, skipped } = agy.readRuns(logDir);

for (const r of runs) {
	const g = numstat(r.range, root);
	r.insertions = g.insertions;
	r.deletions = g.deletions;
	if (r.commits === null) r.commits = g.commits;
	// A run whose tokens were never recorded prices to null, not to free.
	if (r.tokens.total === null) {
		r.usd = null; r.priced = false;
	} else {
		const p = priceOf(r.model, {
			in: r.tokens.in || 0, out: r.tokens.out || 0,
			cache_read: 0, cache_write: 0,
		}, prices);
		r.usd = p.usd; r.priced = p.priced;
	}
}

const turns = claude.readTurns(projectsDir, slug);
const c = claude.summarise(turns, gapS);
const model = turns.length ? turns[turns.length - 1].model : 'unknown';
const pm = priceOf(model, c.main, prices);
const ps = priceOf(model, c.sidechain, prices);

if (!turns.length) {
	skipped.push({
		path: path.join(projectsDir, slug),
		reason: 'no Claude transcripts found — Claude\'s side of every split reads as zero',
	});
}

const out = {
	generated: new Date().toISOString(),
	root,
	idle_gap_s: gapS,
	prices_updated: prices._updated || 'unknown',
	runs,
	claude: {
		active_s: c.active_s, elapsed_s: c.elapsed_s,
		main: c.main, sidechain: c.sidechain,
		model,
		usd_main: pm.usd, usd_sidechain: ps.usd, priced: pm.priced && ps.priced,
	},
	skipped,
};

const outDir = path.join(root, workspace, 'bench');
fs.mkdirSync(outDir, { recursive: true });
const outFile = path.join(outDir, 'runs.json');
fs.writeFileSync(outFile, JSON.stringify(out, null, 2) + '\n');

const partial = runs.filter(r => r.quality === 'partial').length;
console.log(`collected ${runs.length} run(s) -> ${path.relative(root, outFile)}`);
if (partial) console.log(`  ${partial} run(s) logged before instrumentation — reported as partial, not as zero`);
if (skipped.length) {
	console.log(`  ${skipped.length} source(s) SKIPPED — the split below them is incomplete:`);
	for (const s of skipped.slice(0, 10)) console.log(`    ${path.basename(s.path)} — ${s.reason}`);
}
```

```markdown
### Measuring the split

`.agy/dispatch` prints a `share` line for the run it just did — the lines agy
```

## Notes for the implementer

**Assertion counts are guidance, not gates.** Each task states the expected total so you can tell whether your new assertions actually ran. If the number is off by a few because you split an assertion differently, that is fine — `0 failed` is the gate.

**The selftest stubs `agy` and aborts if the real CLI is on PATH.** Never "fix" that abort by unstubbing it; it exists so the suite cannot spend quota.

**Prices in `prices.json` are placeholders dated 2026-08-14.** Check them against current published pricing before quoting any dollar figure to anyone. The file exists so this is a data edit.

**Do not add a blended score.** Several panels will look like they want averaging into one number. That number would hide the case the whole benchmark exists to catch: agy writing most of the lines while Claude burns most of the tokens supervising it.
